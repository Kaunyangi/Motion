# Motion × Trybe

Trybe is Motion Trybe Ventures Corporation's youth-culture app: sign up, pick
what you're here for, and win paid brand gigs through a real Brand
Marketplace — invoiced, watermarked, and paid out to a Motion Pay wallet.

The full-stack implementation lives in [`backend/`](backend/README.md): a
single Node.js process serving both the API and the frontend. See that
README for the quick start, architecture, and full API reference.

```bash
cd backend
npm install
npm start   # http://localhost:4000
```
