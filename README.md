# Motion

The operating system for African movement, culture, and money — event ticketing,
flight booking, accommodation booking, and a wallet ("Motion Pay"), all behind
one checkout and one integrated, responsive frontend.

See [`motion-backend/README.md`](motion-backend/README.md) for setup and architecture.

```bash
cd motion-backend
npm install
npm start          # http://localhost:4000 — frontend + API, same process
```
